# pic-click

`pic-click` 是一个 Windows 本地截图、标注和桌面贴图工具。产品工作流参考 Snipaste，但使用自己的名称、界面和实现，不包含 Snipaste 的商标、图标或源代码。

## 直接运行

双击 `Start.bat`，或执行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

生成正式单文件程序：

```powershell
Build.bat
```

完成后运行 `dist\pic-click.exe`，无需目标电脑另装 Python。

## 快速操作

| 操作 | 快捷键 / 鼠标 |
| --- | --- |
| 开始截图 | `F1` 或 `Ctrl+Shift+S` |
| 滚动长截图 | 点击“开始框选截图”，框选后在选区底部 Dock 选择“滚动截图” |
| 框选 | 鼠标拖动；窗口在截图前处于前台时会被预选 |
| 调整选区 | 方向键移动；`Ctrl+方向键`扩大；`Shift+方向键`缩小 |
| 全屏 / 上次选区 | `Ctrl+A` / `R` |
| 完成 / 复制 | 框选 Dock 的“完成”进入编辑；`Ctrl+C` 或 Dock“复制”直接复制 |
| 进入标注 / 直接贴图 | 松开鼠标立即进入标注 / `Ctrl+T` 或鼠标中键 |
| 取色 | 移动鼠标查看放大镜，按 `C` 复制 HEX 颜色 |
| 剪贴板贴图 | `F3`，支持图片、图片文件、文字、HEX 颜色和路径列表 |
| 隐藏 / 显示全部贴图 | `Shift+F3` |
| 贴图与标注切换 | `Space` |
| 移动 / 缩放贴图 | 拖动 / 滚轮或 `+`、`-` |
| 调整透明度 | `Ctrl+滚轮` |
| 恢复尺寸与透明度 | 鼠标中键 |
| 旋转 / 翻转 | `1`、`2` / `3`、`4` |
| 贴图右键菜单 | 保存、复制、说明、旋转、翻转、鼠标穿透、隐藏、关闭 |
| 上传云端 | 编辑工具栏或贴图右键选择“上传云端”；成功后链接自动复制 |
| 恢复鼠标交互 | `F4` 关闭所有贴图的鼠标穿透 |
| 关闭 / 恢复贴图 | `Esc` 或 `Ctrl+W` 关闭；剪贴板为空时按 `F3` 恢复最近关闭项 |

标注工具包含矩形、椭圆、箭头、自由画笔、高亮、马赛克、自动编号和原位多行文本块。“移动标注”可选中并拖动文字、序号、画笔和各种形状，选中后按 Delete 可删除；无边框贴图状态下拖动仍移动整张贴图。文字输入使用透明输入层，只显示文字与光标，截图背景保持可见；支持中文输入、换行、双击修改和 Esc 取消。可设置颜色、线宽与字号，支持 `Ctrl+Z` 撤销和 `Ctrl+Y` 重做。每张截图可以关联文字说明及本地图片、视频附件，并从历史记录恢复。

## 本地数据

默认保存于 `%LOCALAPPDATA%\pic-click\captures`。每个记录包含工作原图、标注元数据、说明和附件副本。所有数据留在本机。

主窗口和截图后的编辑工具栏都提供“保存设置”入口。客户可以设置：

- 截图工作资料目录：保存原图、标注元数据、说明和附件。
- 默认 PNG 保存目录：点击“保存 PNG”时优先打开的目录。
- 自动保存 PNG：开启后，每次普通截图、滚动截图或剪贴板贴图创建时，自动在指定目录生成带时间戳的 PNG；后续标注修改会同步更新该 PNG。

设置保存在 `%LOCALAPPDATA%\pic-click\settings.json`，重启后继续生效。通过命令行传入 `--data-dir` 时，只覆盖本次运行的工作资料目录。

## 云端上传

主窗口点击“云端设置”，可选择以下方式：

- **WebDAV**：填写服务 URL、账号、密码和远端目录，适用于 Nextcloud、坚果云、AList 及其他提供 WebDAV 的个人网盘。pic-click 会按需创建远端子目录，再使用 PUT 上传 PNG。
- **HTTP API**：向填写的 API 地址发送 `multipart/form-data` POST，请求中的图片字段名为 `file`；Token 使用 `Authorization: Bearer ...`，用户标识使用 `X-Pic-Click-User`。接口响应应返回 JSON 字段 `url`、`link` 或 `download_url`，也可以配置公开链接基础 URL。

账号密码或 Token 使用当前 Windows 用户的 DPAPI 加密后写入设置文件。可先点“测试并保存”上传一张 16×16 测试图片。开启“每次创建截图后自动上传”后，普通截图、滚动长截图和剪贴板贴图创建时都会在后台上传；编辑标注后的最新版本可从工具栏或右键菜单再次手动上传。

百度网盘不提供 WebDAV，也不接受账号密码直接上传。应先在百度网盘开放平台创建应用并完成 OAuth 授权，再将符合上述格式的上传接口或自建中转服务填入“HTTP API”。这样授权令牌可由服务端刷新，pic-click 无需保存百度账号密码。

## 验证

```powershell
python -m unittest -v
python app.py --smoke-test --data-dir .\test-output
python verify_desktop.py --synthetic
```

自动验证覆盖标注渲染、持久化、附件、文字与颜色贴图、窗口启动、框选事件、贴图、撤销重做、原位文本、自由画笔、缩放、透明度、旋转、翻转、鼠标穿透、凭据加密、WebDAV 和 HTTP API 上传。真实网盘 OAuth、真实屏幕捕获、全局快捷键、系统剪贴板和多显示器 DPI 行为仍需要在登录且未锁屏的交互式 Windows 桌面验收。

滚动长截图不会替用户翻页。点击“开始框选截图”并完成选区后，选区底部显示深色 Dock，可选择完成、滚动截图、复制、贴图或取消。选择“滚动截图”后，程序把焦点和鼠标交还给截图前的网页或文档，用户自行向下滚动；画面稳定后程序自动采集。相同页面、仅顶部广告/时钟变化的页面不会重复加入结果；每一帧只有底部新出现的像素会追加，并在原始分辨率上逐像素校准接缝。每次滚动应保留一部分上一屏内容；如果滚动过快导致没有重叠，控制窗会提示向回滚一点。控制窗会显示本次新增的像素高度。点击“完成”或按 Esc 会拼接已经采集的内容，“取消”会放弃本次长截图，最多采集 50 帧。“捕获当前画面”可用于页面动画导致自动稳定检测困难的情况。

## 当前产品边界

本版本实现了截图、标注、贴图三条核心链路和常用快捷操作。窗口/控件层级自动识别、图层对象选择变换、贴图分组、缩略图模式、白板、OCR、二维码和 Snipaste Pro 专属能力未交付。详见 `docs\PRODUCT.md` 与 `docs\QA.md`。
