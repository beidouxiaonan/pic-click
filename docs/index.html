围绕截图后的连续工作流设计，让保存信息和表达想法少一步。

区域与长截图

快速框选屏幕内容，也能继续拼接滚动页面。

屏幕录制

直接录下操作过程并保存为 MJPEG AVI，无需跳转第三方工具。

✎

完整标注

矩形、圆形、箭头、画笔、马赛克、序号和文字集中在 Dock。

▣

桌面贴图

把截图、剪贴板文字或颜色固定在桌面上，随用随看。

≡

历史记录

回到之前的截图继续查看和编辑，减少重复工作。

⌘

本地与连接

默认本地保存，同时提供 WebDAV 与 HTTP API 连接能力。

三步完成

从看见，到分享，
不离开当前思路。

默认流程足够短，自定义空间也足够大。

  1. 01

    框选或录制

    按下快捷键，立即捕捉需要的内容。

  2. 02

    在 Dock 上处理

    标注重点、打码信息，或将画面钉在桌面。

  3. 03

    复制、保存、继续

    带着结果回到原来的任务，不被工具打断。
