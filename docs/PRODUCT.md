# pic-click 产品与技术交付说明

## 产品定位

pic-click 面向需要在原内容旁快速比对、讲解和留存信息的 Windows 用户。核心价值是把截图变成可持续停留在桌面的工作资料，并允许为截图附加文字、图片和视频说明。

## 用户主流程

1. 用户按 F1，系统冻结当前多屏画面并预选前台窗口。
2. 用户拖动或用键盘调整区域，可复制或直接贴图。
3. 用户用形状、画笔、高亮和文本块标记重点，支持撤销重做。
4. 用户将结果贴到桌面，移动、缩放、旋转、翻转、调整透明度或设置鼠标穿透。
5. 用户也可先框选区域，再使用极简控制 Dock 录制该区域并保存为本地视频。
6. 用户为记录补充说明和附件；之后通过历史记录继续查看和编辑。
7. 用户按 F3 将剪贴板中的图片、文字、颜色或文件路径转换成贴图。
8. 用户可将截图手动或自动上传至 WebDAV/个人网盘 API，并复制分享链接。

## 验收标准

- F1 能进入全屏框选，Esc 能取消，背景截图不模糊。
- 方向键能按像素移动选区，组合键能改变选区尺寸。
- Enter/Ctrl+C 输出图片；Ctrl+T 生成置顶贴图。
- 标注输出与屏幕预览一致，撤销和重做不会损坏原图。
- 文本在点击位置原位输入，允许换行、修改和取消。
- F3 能处理图片、文字及 HEX 颜色，生成的贴图可移动和缩放。
- Ctrl+滚轮改变单张贴图透明度；1–4 执行旋转和翻转。
- 鼠标穿透开启后 F4 可恢复交互，防止贴图永久无法操作。
- 说明、标注和附件关联在重启后可从历史记录恢复。
- WebDAV 或 HTTP API 配置后可在后台上传，成功链接写入截图元数据且可复制。
- 区域视频录制可暂停、继续、完成和取消，并输出带索引的 MJPEG AVI 文件。

## 架构

当前版本采用 Python 3、Tkinter 和 Pillow，Windows API 负责全局热键、剪贴板、窗口穿透和 DPAPI 凭据加密。每张截图用独立目录保存 `original.png`、`metadata.json` 与 `attachments/`，避免数据库迁移成本。云端上传通过 WebDAV 或通用 HTTP API 在后台执行，PyInstaller 生成单文件 Windows 程序。

该架构适合快速验证产品和轻量离线使用。若进入商业发行阶段，建议迁移到 C# + WinUI 3/Avalonia 或 C++ + Qt 6，重点重构屏幕捕获、DPI 坐标、画布对象模型、单实例托盘服务、自动更新和崩溃恢复。

## 版本规划

- P0 已交付：截图、区域视频录制、手动滚动长截图、键盘调整、放大镜取色、常用标注、马赛克、序号、透明原位文本、标注对象选择移动、贴图、剪贴板多来源、历史、附件、保存设置、WebDAV/HTTP API 云端上传、托盘、可执行包。
- P1：可拖拽选区锚点、窗口/控件层级识别、对象缩放与旋转、主流网盘原生 OAuth 向导。
- P2：贴图分组、缩略图、白板、OCR/二维码、本地索引、安装包与自动更新。

这里的优先级是本项目的版本规划，不表示与 Snipaste 各版本一一对应。
